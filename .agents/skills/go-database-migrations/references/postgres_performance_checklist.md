# قائمة تدقيق أداء وموثوقية قواعد البيانات (PostgreSQL Performance Checklist)

تُستخدم هذه القائمة للتأكد من كفاءة استعلامات وتصميم قاعدة البيانات قبل اعتماد الترحيلات.

---

## بنود التدقيق

- [ ] هل تحتوي جميع المفاتيح الأجنبية (Foreign Keys) على فهارس B-Tree مخصصة لمنع المسح المتسلسل (Seq Scan)؟
- [ ] هل تم إنشاء الفهارس الكبيرة باستخدام `CONCURRENTLY` خارج كتل الـ Transaction؟
- [ ] هل العمليات التي تقرأ وتعدل الأرصدة أو المخزون تستخدم `SELECT ... FOR UPDATE`؟
- [ ] هل الأقفال المتعددة مرتبة تصاعدياً لتجنب مشكلة الـ Deadlock؟
- [ ] هل يتم استدعاء `defer rows.Close()` فورياً بعد كل استعلام `Query()`؟
- [ ] هل يتم فحص `rows.Err()` بعد انتهاء حلقة القراءة `rows.Next()`؟
- [ ] هل تم ضبط حدود مجمّع الاتصالات (`MaxConns`, `MinConns`, `MaxConnIdleTime`) بصورة مدروسة؟
- [ ] هل تم تجنب ترحيلات الـ DDL التي تفرض أقفالاً حصرية على الجداول الحية؟

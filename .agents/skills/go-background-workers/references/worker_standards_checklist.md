# قائمة تدقيق عمال الخلفية (Background Worker Checklist)

تُستخدم هذه القائمة للتأكد من صمود وجودة عمال الخلفية قبل اعتمادهم للإنتاج.

---

## بنود التدقيق

- [ ] هل كل حلقة Goroutine لعامل خلفية محاطة بـ `defer/recover` لمنع انهيار العملية الرئيسية؟
- [ ] هل تستمع حلقة العامل إلى `ctx.Done()` في كل عملية انتظار أو دورة؟
- [ ] هل يتم إيقاف أي عداد `time.NewTicker` باستخدام `defer ticker.Stop()`؟
- [ ] هل تم تجنب استخدام `time.Tick()` و `time.Sleep()` في الحلقات المستمرة؟
- [ ] هل يتم تتبع العمال بواسطة `sync.WaitGroup` للانتظار حتى انتهاء المهام الحالية عند الإيقاف؟
- [ ] هل تتوقف كافة خيوط العمال قبل إغلاق مجمّعات اتصالات قواعد البيانات (`dbPool.Close()`)؟
- [ ] هل تم تطبيق التراجع الأسي مع التشويش العشوائي (Exponential Backoff with Jitter) للاتصالات الخارجية؟

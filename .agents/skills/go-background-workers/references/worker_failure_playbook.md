# كتيب استجابة أعطال عمال الخلفية (Worker Failure Playbook)

يوضح هذا الدليل كيفية التصرف عند حدوث أعطال متكررة في مهام الخلفية أو تعليق العمليات.

---

## مصفوفة استكشاف الأعطال وحلها

| العَرَض التشغيلي | السبب الجذري المحتمل | إجراء الحل المعياري |
| :--- | :--- | :--- |
| **Worker Panic Logs** | خطأ في معالجة Null Pointer أو تحويل نوع غير متوافق | يتم التقاطه بـ `recover()` تلقائياً. فحص مسار الخطأ في `logs/error.log` وإصلاح الشرط الحدي في كود المهمة. |
| **تعليق السيرفر عند الإيقاف (Hanging Shutdown)** | العامل لا يفحص `ctx.Done()` في حلقة التكرار أو يستخدم `time.Sleep` | تحويل الانتظار إلى `select` والاستجابة الفورية لـ `ctx.Done()`. |
| **تداخل الدورات (Overlapping Cycles)** | المهمة تستغرق وقتاً أطول من فاصل الـ Ticker | تفعيل التحقق الذري `atomic.Bool.CompareAndSwap` لتخطي الدورات المتداخلة، أو مد فترة الفاصل الزمني. |
| **تسريب اتصالات قاعدة البيانات** | العامل ينفذ استعلامات متكررة دون إغلاق `rows.Close()` | التأكد من استخدام `defer rows.Close()` وتفادي الاحتفاظ بالاتصالات داخل المتغيرات العامة. |
| **فشل متكرر في خدمة خارجية** | خادم البريد أو بوابة الدفع متوقفة مؤقتاً | تفعيل `RetryWithBackoff` مع وضع حد أقصى للمحاولات ومهلة زمنية (Timeout). |

# أنماط معالجة الطوابير والدفعات (Queue & Batch Processing Patterns)

في أنظمة مثل `email-queue-processor` أو معالجة الإشعارات، تتجمع المهام في طابور انتظار وتتطلب معالجة سريعة وفعالة.

---

## 1. المعالجة بالدفعات (Batch Processing)

بدلاً من معالجة كل رسالة أو سجل بشكل فردي وفتح معاملة قاعدة بيانات منفصلة لكل عنصر:

- تجميع العناصر في دفعات (مثلاً: 50 إلى 100 عنصر في الدفعة).
- تنفيذ استعلام مجمّع: `UPDATE queue SET status = 'processed' WHERE id = ANY($1)`.
- تقليل استهلاك شبكة قاعدة البيانات وتسريع الأداء بعشرات الأضعاف.

---

## 2. النمط الآمن لتفريغ الطابور عند الإغلاق (Drain on Shutdown)

عندما يستقبل معالج الطابور إشارة الإيقاف:

1. يتوقف عن سحب مهام جديدة من الطابور.
2. ينهي معالجة الدفعة الحالية قيد التنفيذ (In-flight Batch).
3. يحدث حالة المهام في قاعدة البيانات.
4. يخرج بسلام قبل انتهاء مهلة الـ `ShutdownTimeout`.

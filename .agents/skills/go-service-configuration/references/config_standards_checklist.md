# قائمة تدقيق معايير الإعدادات (Configuration Standards Checklist)

تُستخدم هذه القائمة لفحص جودة وأمان نظام الإعدادات في أي خدمة Go قبل اعتمادها للإنتاج.

---

## بنود التدقيق والتحقق

### 1. طبقات التحميل والأسبقية

- [ ] هل يدعم التطبيق قيماً افتراضية صلبة وآمنة (`Defaults()`) تعمل دون الحاجة لملفات خارجية؟
- [ ] هل يتم دمج ملفات الـ JSON/YAML فوق الـ Defaults دون مسح المفاتيح غير المذكورة؟
- [ ] هل تتفوق المتغيرات البيئية (Env Vars) على ملف التكوين؟
- [ ] هل يدعم النظام متغيرات البيئة البديلة الشائعة (`PG*`, `DATABASE_URL`)؟

### 2. الفشل الاستباقي والتحقق (Validation)

- [ ] هل يتم فحص كافة الإعدادات فوراً في المرحلة الأولى (`Phase 1: Init`) قبل فتح منافذ الشبكة؟
- [ ] هل يستخدم النظام مجمّع أخطاء متعددة (Multi-Error Report) يعرض كافة المشاكل دفعة واحدة؟
- [ ] هل يتم التحقق من أن أرقام المنافذ تقع بين 1 و 65535؟
- [ ] هل يتم التأكد من أن مهلة الإغلاق أكبر من مدة التصريف (`ShutdownTimeout > DrainDuration`)؟

### 3. الأمان وحجب الأسرار (Secret Security)

- [ ] هل يتم حجب كلمات المرور ومفاتيح JWT ورموز المصادقة بالقيمة `***` عند الطباعة في السجلات؟
- [ ] هل يتم حجب كلمات المرور داخل روابط الاتصال (`postgres://user:***@host/db`)؟
- [ ] هل تُحفظ ملفات الإعدادات على القرص بأذونات مقيدة وصارمة `0600` (للمالك فقط)؟
- [ ] هل يتم استخدام خوارزميات تجزئة قوية (PBKDF2 / Argon2id) لكلمات المرور الإدارية؟

### 4. حفظ الملفات والمتانة (Persistence)

- [ ] هل تستخدم عمليات حفظ التكوين على القرص الكتابة الذرية (Atomic Write: temp file -> sync -> rename) لمنع تلف الملفات أثناء انقطاع التيار؟
- [ ] هل تدعم الحقول الزمنية التحليل المرن للنصوص (`"5s"`, `"10m"`) والأرقام؟

### 5. التوثيق الذاتي

- [ ] هل تحتوي تراكيب الـ Structs على وسوم `env:` و `default:` و `desc:` كافية لإنشاء نموذج `.env.example` تلقائياً؟

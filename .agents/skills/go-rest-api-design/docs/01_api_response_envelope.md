# هيكل غلاف الاستجابة الموحد (Unified Response Envelope)

في المشاريع الكبيرة ذات النطاقات المتعددة (مثل 42 موديول في Cashflow)، يؤدي تفاوت هيكل الاستجابة بين المطورين إلى تعقيد عمل مطوري الواجهات الأمامية وتطبيقات الموبايل.

---

## مواصفات غلاف النجاح (Success Envelope)

تلتزم كافة الاستجابات الناجحة بالنموذج التالي:

```json
{
  "data": {
    "id": "inv_12345",
    "amount": 1500.00,
    "status": "PAID"
  },
  "meta": {
    "request_id": "req_abc123",
    "timestamp": "2026-09-14T05:30:00Z"
  }
}
```

### القواعد الإلزامية

1. **`data`**: يحتوي على الكيان المطلوب (كائن مفرد أو مصفوفة من الكائنات).
2. **`meta`**: يحتوي على البيانات الوصفية والإحصائية الخاصة بالطلب:
   - `request_id`: رقم تتبع الطلب لتسهيل مراجعة السجلات.
   - `page`, `limit`, `total_count` (في طلبات القوائم).
   - `execution_time_ms`: زمن المعالجة (اختياري).

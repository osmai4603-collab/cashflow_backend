# الشفافية والمقاييس التشغيلية (Observability & Metrics)

تعتمد القدرة على إدارة الخادم في الإنتاج على مدى "شفافيته". توفر المهارة آلية لجمع وعرض البيانات الحيوية فورياً.

## المقاييس الأساسية (Core Metrics)

يتم توفير مسار `/metrics` يعيد بيانات بصيغة JSON تشمل:

### 1. موارد النظام (System Resources)
- **الذاكرة (Memory)**: تتبع الذاكرة المحجوزة (`Alloc`) والذاكرة الكلية وذاكرة الـ `Heap`.
- **المعالج (CPU)**: (في الأنظمة التي تدعم ذلك) تتبع استهلاك المعالج للعملية.
- **Goroutines**: مراقبة عدد الخيوط البرمجية النشطة لاكتشاف التسريبات (Goroutine Leaks).

### 2. جودة حركة المرور (Traffic Quality)
- **العدادات**: إجمالي الطلبات، والطلبات الناجحة (`2xx`) مقابل الأخطاء (`4xx`, `5xx`).
- **الأداء (Latency)**: متوسط وقت الاستجابة بالملي ثانية.

### 3. صحة قاعدة البيانات (Database Health)
- **الاتصالات النشطة**: كم عدد الاتصالات المفتوحة حالياً؟
- **الانتظارات (Wait Count)**: هل هناك طلبات تنتظر الحصول على اتصال؟ (مؤشر على حاجة النظام لزيادة حجم الـ Pool).

## أدوات المراقبة الفورية (Live Monitoring)
تتضمن المهارة استخدام أدوات بسيطة (مثل سكريبتات Bash) لتحويل بيانات JSON إلى لوحة تحكم ملونة (Dashboard) داخل الطرفية، مما يغني المطور عن أدوات المراقبة المعقدة أثناء التطوير أو التشخيص السريع.
